# avr-cl: Ship Plan (July 2026)

## Positioning
**avr-cl is a LAYER, not a framework.** It's the forgetting-prevention layer that sits between your training stages. You keep using TRL/Axolotl/Unsloth for training. avr-cl checks if your model forgot between stages, and repairs it.

- **Product**: layer ("forgetting-prevention layer for LLM post-training")
- **Paper**: framework ("continual post-training framework") — academic framing only
- **Code**: both `avr.run()` (full loop) AND `avr.check_drift()` + `avr.repair()` (layer API)

## The 2026 context
- CL went from academic to production-pain (Zylos: "users expect agents to not forget")
- Letta launched learning-sdk (Feb 2026) — they own the memory/retrieval layer
- GRPO ate post-training (DeepSeek-R2, all reasoning models)
- avr-cl's open niche: weight-space VERIFY+REPAIR — nobody else does this

## The pitch
"Fine-tune sequentially. avr-cl checks if you broke the model. And fixes it."
