# V3: Method Tuning

Tunes the Anchor-AVR method on the V2 framework. Compares against EWC, Replay, and Freeze baselines. Mirrors V2's file layout.

## Files

- `config.py`, `data.py`, `methods.py`, `train.py`, `evaluate.py` — V2 framework, V3 configs
- `anchors.py` — anchor snapshot management
- `modal_run.py` — Modal.com remote runner
- `smoke_test.py` — 1-minute sanity check

## Status

Superseded by V4 (Kaggle port) and ultimately by the single-file scripts (v9 onward).
